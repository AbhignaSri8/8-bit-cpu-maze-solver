# 8-Bit CPU Maze Solver

## Overview
A custom 8-bit CPU designed using Logisim Evolution as an academic Computer Organization and Architecture project.

## Objective
To explore how CPU components can work together to solve an 8×8 maze using Depth-First Search (DFS).

## Components
- 8-bit datapath and ALU
- Register file and control unit
- Program Counter and instruction ROM
- Maze RAM and visited memory
- Stack memory for backtracking
- Finite State Machine (FSM) for stack control

## Tools Used
- Logisim Evolution
- Digital logic design
- Assembly-style machine instructions

## Project Status
The CPU components and selected instructions have been tested.LED matrix visualization remain works in progress.
